# 无最终答案的最小证据双轨实验

## 共同生成阶段

被测模型只读取任务并输出六个字段的最小结构化证据。它不生成最终答案、完整解法、完整代码、完整证明或完整 Chain-of-Thought，也不输出能力、信心或难度自评。

共同生成结果默认写入：

```text
outputs/task_conditioned_capability_sufficiency_no_answer/model_evidence.json
```

该文件额外保存原始 prompt token IDs 和 generated token IDs，保证两个观察轨使用完全相同的生成序列。

## 轨一：LLM-Judge 输出证据

```text
model_evidence.json
  → extract_judge_evidence.py
  → llm_judge/judge_evidence.json
  → score_sufficiency.py
  → llm_judge/sufficiency_results.json
  → build_report.py
  → llm_judge/report.md
```

Judge 只提取语义事实，不直接输出能力分数。固定 Python 规则产生六维充分度、总体充分度、相对困难度和瓶颈。该轨不读取 Hidden States。

## 轨二：生成证据过程中的 Hidden States

```text
model_evidence.json
  → extract_hidden_state_features.py
  → hidden_state/latent_metrics.json
  → build_hidden_state_report.py
  → hidden_state/report.md
```

隐藏状态轨只读取共同生成结果，不读取 `judge_evidence.json` 或充分度分数。脚本对同一 token 序列做因果 replay，用 forward hook 捕获最后四层，并按六个顶层字段的 JSON value span 对齐预测每个证据 token 之前的状态。

每个具有实际证据且不少于三个 token 的字段独立计算：

- effective-rank dispersion entropy；
- mean adjacent-state drift；
- trajectory direction change；
- terminal instability；
- cross-layer disagreement；
- 与前一个可测字段的 boundary jump（诊断项）。

五个主指标做无权平均，得到探索性的 `latent_load_proxy`。该值尚未校准，不能解释为能力充分度、答案正确率或客观难度。字段为空时记为 `empty_evidence`，不打零分。
