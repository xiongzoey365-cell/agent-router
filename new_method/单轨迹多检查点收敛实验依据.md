# Qwen3-8B 单轨迹、多检查点硬指标实验依据

## 1. 目标与边界

本实验只生成一条确定性的预推理轨迹，在多个检查点提取可重复计算的内部表示与文本轨迹指标，观察推理是否逐步稳定、是否出现重复回访。

- 每题只生成一条预推理轨迹，不做多次采样；
- 不要求模型输出 readiness、blockers、收敛标签或方法标签；
- 不生成完整答案，不评价答案正确性；
- 不使用 L1–L5 参与计算、阈值选择或权重拟合；
- 第一阶段只输出原始指标分布，不预设未经校准的绝对收敛阈值；
- `difficulty_level` 仅随结果保存，方便后续人工分析。

本实验衡量的是当前模型在有限预推理中的状态变化，不等于题目的绝对难度。

## 2. 一条预推理轨迹

使用 Qwen3-8B 官方 Chat Template，系统提示要求分析关键约束、候选路径和障碍，但不生成完整答案。使用 Thinking 模式、`do_sample=False`，固定生成最多256个新 Token；实现默认设置 `min_new_tokens=max_new_tokens=256`，保证64、128、192、256四个检查点来自同一条完整轨迹。

检查点固定为：

```text
64, 128, 192, 256
```

如果模型提前结束，只分析实际可用的检查点，并记录 `ended_early`。

## 3. 固定探测文本与 Hidden State

直接比较不同生成 Token 的 Hidden State 会混入词性、数字、标点和句法位置差异。本方案在每个检查点的预推理前缀后追加同一段固定文本：

```text
当前已经确定的核心解题方法是：
```

对“原题 + 预推理前缀 + 固定探测文本”执行一次因果前向传播，读取固定探测文本对应位置的 Hidden State。只保留最后4层：

1. 每层的探测文本位置向量做 L2 归一化；
2. 对探测文本的多个 Token 求平均并再次归一化；
3. 对最后4层取平均并再次归一化；
4. 得到当前检查点的一个向量 `z_t`。

固定探测文本在所有检查点完全相同，因此比较的是“当前预推理前缀改变后，模型对同一探测位置的内部表示如何改变”。探测前向只读 Hidden State，不生成额外文本。

## 4. 硬指标

### 4.1 相邻检查点表示距离

对相邻检查点：

\[
d_t=1-\cos(z_t,z_{t-1})
\]

`probe_adjacent_distances` 越大，表示新增预推理仍明显改变模型对解题路径的表示；如果后续距离逐步变小，说明表示变化在减弱。

### 4.2 末段表示距离

对最后最多三个检查点计算所有两两距离，记录：

- `probe_terminal_max_distance`：末段最大距离；
- `probe_terminal_mean_distance`：末段平均距离；
- `probe_last_distance`：最后两个检查点之间的距离。

这些是原始值，不自动解释为已经收敛。

### 4.3 词面重复率

对每个检查点之前的预推理 Token 序列构造4-gram。重复出现的4-gram数量除以全部4-gram数量，得到 `lexical_repetition_rate`。

重复率高可能表示机械复述或循环，也可能来自代码、公式和固定模板，因此只作为辅助指标。

### 4.4 非相邻片段回访

将预推理按32 Token切分。对第3段及之后的片段，与此前非相邻片段计算最长连续相同 Token span。若达到默认8 Token，则该片段记为回访。

记录：

- `segment_revisit_rate`：检查点之前发生回访的片段比例；
- `max_revisit_span`：最大连续回访长度；
- `loop_suspect`：是否出现至少8 Token的非相邻连续回访。

这是一个明确的文本结构规则，不能单独等同于题目困难。

### 4.5 路径修正词计数

记录固定中英文修正词，如 `wait`、`however`、`actually`、`重新考虑`、`前面不对`、`但是` 等出现次数，保存为 `path_reversal_count`。该值用于辅助观察路径反转，不参与收敛判定。

## 5. 第一阶段输出规则

第一阶段不设 `stable_candidate` 或难度总分，只输出：

- 生成是否达到预算；
- 各检查点的探测距离序列；
- 末段最大/平均距离；
- 各检查点重复率与回访率；
- 是否存在结构性循环嫌疑；
- 修正词数量与运行成本。

只有取得独立校准数据、观察指标分布后，才允许确定距离阈值或稳定规则。不得直接把 `0.95` 等任意余弦阈值写成收敛标准。

后续若要启用动态停止，应在第二阶段依据第一阶段分布制定规则，例如要求末段距离低于校准阈值且重复率低于校准阈值，并连续满足两个检查点。第二阶段规则必须在独立数据上验证。

## 6. 输出

默认目录为 `outputs/checkpoint_convergence/`：

- `results.json`：模型配置、预推理文本、逐检查点指标；
- `results.csv`：逐题扁平摘要；
- `report.md`：原始指标汇总。
