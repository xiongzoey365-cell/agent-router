# Qwen3-8B 结构化浅推理可解性探针（首版）

## 1. 目标

让模型先完成一份短的结构化预分析，再观察预分析过程中 Hidden State 的变化趋势，输出一个由程序计算的 `SolveabilityProxyScore`。该分数表示“当前模型在规定浅推理预算内形成可执行解题草案的程度”，不表示真实正确率，也不表示经过校准的成功概率。

## 2. 实验边界

- 每道题只生成一次浅推理，不做多次采样；
- 使用 Qwen3-8B 官方 Chat Template，`enable_thinking=False`、`do_sample=False`；
- 最多生成384个新 Token；
- 模型只输出三段预分析，不输出完整答案、最终代码或完整证明；
- 模型不输出难度、置信度或可解性分数；
- `difficulty_level` 只保存，不参与分数计算；
- 不评价完整答案质量，不计算语义熵，不融合其他方法。

## 3. 结构化浅推理格式

系统提示要求模型严格输出：

```text
关键约束：列出必须满足的条件、输入限制和评价要求。
核心方案：给出准备采用的方法和2–4个关键步骤，不展开完整答案。
待补环节：指出仍需推导、验证或实现的关键部分；如果没有，写“无”。
```

程序从原始文本中解析三段内容，但保留原始输出。解析只判断字段是否存在和是否非空，不相信模型自报的“容易”“有把握”等措辞。

## 4. Hidden State 轨迹

### 4.1 自然生成窗口

将实际生成 Token 按32 Token切成窗口。对每个窗口、最后4层 Hidden State：

1. 对每层窗口向量做 L2 归一化；
2. 对最后4层求平均并归一化；
3. 得到自然生成窗口向量 `g_t`。

计算相邻窗口距离：

\[
d^g_t=1-\cos(g_t,g_{t-1})
\]

记录窗口距离序列、前半段平均距离、后半段平均距离和变化衰减。

### 4.2 固定探测位置

为了减少不同词性和句法位置造成的影响，在每个已生成前缀后追加同一段固定文本：

```text
当前核心解题方案是：
```

只做一次前向传播，提取该固定文本最后位置的最后4层 Hidden State并平均，得到 `p_t`。计算：

\[
d^p_t=1-\cos(p_t,p_{t-1})
\]

固定探测表示只作为稳定性特征，不被解释为答案正确性。

## 5. 文本重复与结构指标

程序计算：

- `lexical_repetition_rate`：每个检查点前缀的4-gram重复比例；
- `segment_revisit_rate`：32 Token片段与更早非相邻片段的连续回访比例，默认连续8 Token视为一次回访；
- `path_reversal_count`：固定中英文修正词计数；
- `structure_completeness`：三个结构化字段中非空字段的比例；
- `pending_is_empty`：待补环节是否明确写“无”。

重复率和回访率高时，稳定表示可能是机械复述，分数需要受到惩罚。

## 6. 可解性代理分数

分数由程序计算，模型不输出分数。第一阶段使用批次内归一化，避免直接指定未经验证的 Hidden State 绝对阈值。

### 6.1 子分数

对全部成功题目的 `terminal_probe_distance` 取90百分位 `q90`：

\[
S_{stable}=1-\min(1,terminal\_probe\_distance/(q90+\epsilon))
\]

前后变化衰减：

\[
S_{decay}=clip((early\_distance-late\_distance)/(early\_distance+\epsilon),0,1)
\]

重复安全度：

\[
S_{repeat}=1-\max(lexical\_repetition\_rate,segment\_revisit\_rate)
\]

结构完整度：

\[
S_{structure}=structure\_completeness
\]

### 6.2 分数组合

\[
SolveabilityProxyScore=100\times(
0.30S_{stable}+0.20S_{decay}+0.20S_{repeat}+0.30S_{structure})
\]

该权重是首版工程约定，不是根据L1–L5拟合得到的权重。结果必须同时保留四个子分数和原始指标。分数只能用于同一模型、同一提示词、同一批次内的初步排序。

## 7. 输出

默认目录为 `outputs/structured_shallow_probe/`：

- `results.json`：完整预分析、Hidden State趋势、原始指标和代理分数；
- `results.csv`：逐题摘要；
- `report.md`：分数分布和逐题结果。
