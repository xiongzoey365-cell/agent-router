要证明对于任意正整数 $ n $，$ n^5 - n $ 能被 30 整除，可以考虑将 30 分解为 $ 2 \times 3 \times 5 $，并分别证明 $ n^5 - n $ 能被 2、3 和 5 整除。首先，对于模 2，可以利用 $ n^5 \equiv n \pmod{2} $，因为 $ n^5 \equiv n \pmod{2} $ 对于所有整数 $ n $ 成立，这可以通过观察 $ n $ 为偶数或奇数时的幂次结果来验证。接着，对于模 3，可以利用费马小定理，即 $ n^3 \equiv n \pmod{3} $，从而 $ n^5 = n^3 \cdot n^2 \equiv n \cdot n^2 = n^3 \equiv n \pmod{3} $，因此 $ n^5 - n \equiv 0 \pmod{3} $。对于模 5，同样应用费马小定理，$ n^5 \equiv n \pmod{5} $，因此 $ n^5 - n \equiv 0 \pmod{5} $。由于 2、3 和 5 两两互质，根据中国剩余定理，若 $ n^5 - n $ 能被 2、3 和 5 整除，则它能被 $ 2 \times 3 \times 5 = 30 $ 整除。因此，只需验证 $ n^5 - n $ 能被 2、3 和 5 整除即可。若在验证过程中发现任何例外情况，需进一步检查模运算的正确性或考虑其他可能的数学工具，如因式分解或归纳法。若需要更深入的验证，可以尝试对 $ n^5 - n $ 进行因式分解，例如 $ n^5 - n = n(n^4 - 1) = n(n^2 - 1)(n^2 + 1) = n(n - 1)(n + 1)(n^2 + 1) $，并分析其因数结构是否包含 2、3 和 5 的倍数。
